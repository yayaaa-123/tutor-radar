# 家教雷达 · Tutor Radar

家教雷达是一款 Windows 本地工具，帮你从微信群里找到适合自己的家教订单。登录电脑版微信，填写可教科目、上课时间和通勤出发地，再选几个家教群，雷达就会定期只读检查群消息，提取订单并按你的条件筛选。

你可以查看订单原文、评分依据和公交路线，收到合适的新单提醒，再自行决定是否联系。雷达不会自动发消息或抢单。

## 主要功能

- **实时监控**：每 5 秒检查选定的微信群，各群候选分开显示。
- **筛选和评分**：按个人条件筛单，通过固定规则给出 S / A / B / C 等级、推荐理由和待确认项。
- **地图与通勤**：在地图上查看有坐标的候选，点击地点查看单程公交时间和路线。
- **订单管理**：展开查看订单原文，可以将不合适的单移入「已拒绝」。过期订单按滚动 48 小时清理。
- **可选本地 AI**：通过 Ollama 补全难解析的订单字段，并补充推荐说明。基础筛选和固定评分可以直接使用。

## 下载与安装

如果 [Releases](../../releases) 中有 Windows 安装包，下载名称以 `x64-setup.exe` 结尾的文件，双击后按中文向导安装。安装包自带运行所需的 Python 后台。

首次打开时，先确认电脑版微信已登录，然后跟着向导填写个人条件、选择要监控的家教群。回到主界面后，可以查看雷达是否已读取消息。即使暂时没有符合条件的候选，后台也会继续检查新消息。

## 数据与兼容性

订单数据保存在本机。启用地图时，地址解析和通勤查询所需的地点信息会发给高德。选装的 AI 模型在用户自己的电脑上运行，下载模型前会显示保存路径并要求确认。

项目面向 Windows 11 x64。微信读取曾在电脑版微信 **4.1.12.55** 上验证，其他版本的兼容性有待确认。公开源码只提供地图配置模板，从源码运行时可填写自己的高德凭据。
