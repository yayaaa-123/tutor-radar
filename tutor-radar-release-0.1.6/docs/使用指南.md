# 家教雷达使用指南

首次安装见[安装指南](安装指南.md)。

## 看订单

在主界面选择一个已监控的群，再按「全部候选」或 S、A、B、C 等级筛选。展开卡片里的「查看评分依据、分析与原文」，可以查看订单原文、评分依据和缺失信息。点「不合适，移到已拒绝」可以隐藏该候选，误操作时从「已拒绝」里恢复。

「监控运行中」只表示后台在检查群聊。如果还没有订单，先看页面提示。读到消息但解析出 0 条订单，可能是最近的消息没有可识别订单。解析出了订单但候选为 0，则可能没有符合个人条件的单。新群首次回看有条数上限，之后会继续检查新消息。

## 修改条件和群聊

- 「我的条件」可随时修改个人画像和通勤出发地。保存后，新消息按新条件处理，已经生成的候选不会自动重筛。
- 「管理群聊」用于添加或停止监控。找不到群时，先在电脑版微信打开该群，再回到雷达刷新。

## 看地图和通勤

切换到「地图」，点击带坐标的候选点，查看地址和公交路线。底图与通勤查询是不同步骤。地图已显示但没有候选点时，说明当前候选还没有可用坐标。一般无需使用「导入内测地图配置」。

## 可选：启用本地模型

基础筛单和固定评分可直接使用。模型可以补全难解析的订单字段，帮助发现更多合适订单，并补充推荐解释。

1. 打开「工具 → 本地模型（可选）」，选择模型保存位置。已有模型就选原 Ollama 模型目录。
2. 点「开始检测」。若电脑没有 Ollama，点「前往安装 Ollama」，运行官方安装器，再回来点「重新检测」。
3. 找到已有模型会复用。确实需要下载时，核对界面显示的完整路径，确认后才开始下载。模型文件有数 GB，下载时可以让它在后台继续。
4. 显示「模型已准备好」后，运行中的雷达会在下一轮检查时启用。

## 暂停、退出与卸载

关掉窗口后，雷达会留在 Windows 右下角系统托盘。右键图标可暂停或继续监控，也可选择「彻底退出」。电脑休眠或微信退出时，雷达无法继续读群。

通过 Windows「已安装的应用」或安装目录里的 `uninstall.exe` 卸载。单独安装的 Ollama 和独立目录中的模型会保留。如果曾把模型放进雷达的应用数据目录，卸载时勾选「删除应用数据」会一起删掉该目录中的模型。
