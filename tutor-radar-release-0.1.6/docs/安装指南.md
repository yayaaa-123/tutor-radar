# 家教雷达安装指南

适用于 Windows 11 的 x64 电脑。开始前请安装并登录电脑版微信，并确认你已经加入要监控的家教群。家教雷达安装包内置后台，基础功能无需单独安装 Python 或 Ollama。

## 1. 下载并安装

1. 从项目发布页下载名称末尾是 `x64-setup.exe` 的安装文件。
2. 双击安装文件。按中文安装向导选择位置，完成后打开「家教雷达」。电脑缺少 WebView2 时，安装程序可能需要联网下载它。
3. 如果 Windows 提示「未知发布者」，先核对文件是不是从项目发布页下载的。本版安装包尚未签名。来源无法确认时请停止安装。

已装过旧版时，先从系统托盘右键点家教雷达，选择「彻底退出」，再运行新版安装包。

## 2. 完成首次设置

1. **设置个人条件。** 选择性别、学历和可教学科，填写通勤出发地。学校和年级可以选填。只接周末就勾选对应选项。点击「保存并选群」。
2. **选择群聊。** 勾选要监控的家教群，点「保存并应用」。找不到群时，先在电脑版微信打开该群，再回到雷达点「刷新微信群」。
3. **确认雷达在读消息。** 回到主界面，看到「监控运行中」表示监控已启动。等界面显示读到了群消息，就能完成向导。暂时没有新消息时可以先关闭窗口，让雷达留在系统托盘继续运行。

接下来可以直接使用筛单和固定评分。地图已经预配，模型可稍后在「工具 → 本地模型（可选）」启用。详见[使用指南](使用指南.md)。
